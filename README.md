# VFS Global Italy Slot Monitor (Казахстан)

Асинхронный Python-бот для непрерывного мониторинга свободных слотов на подачу документов на визу Италии в визовых центрах VFS Global Казахстана (**Астана**, **Алматы**, **Усть-Каменогорск**).

Бот спроектирован для запуска как фоновый Docker-воркер в **Coolify** с удалённым подключением к **Browserless** через WebSocket CDP.

---

## Архитектура и особенности

- **Внешний Browserless**: Внутри контейнера бота не запускается локальный Chromium — бот подключается по WebSocket к независимому сервису Browserless. Это экономит ресурсы и предотвращает утечки памяти.
- **Полная асинхронность**: Сетевые вызовы переведены на `httpx.AsyncClient` и `AsyncOpenAI`, цикл событий `asyncio` не блокируется.
- **Автоматическое восстановление**: При обрыве соединения с Browserless супервизор корректно останавливает задачи, выдерживает backoff и переподключается с сохранением текущего состояния.
- **Безопасная обработка слотов**: При обнаружении слота бот **не закрывает сессию** и не прерывает работу. Он перелогинивается в основной аккаунт, присылает алерт со скриншотом в Telegram, ставит мониторинг на паузу и держит сессию активной, чтобы заявитель мог завершить запись вручную.
- **Интеллектуальный Telegram-ассистент**: Любое текстовое сообщение от администратора в Telegram передается вместе со свежим скриншотом страницы в OpenAI GPT-4o-mini для анализа текущей ситуации.
- **Защита от блокировок (429 и 502)**:
  - Автоматическая ротация донорских аккаунтов при 429 или каждые N кругов.
  - Ожидание 4 минут при ошибках 502/падении серверов VFS.

## Настройка сервиса Browserless

Для развертывания Browserless (например, в Coolify через Docker Image `ghcr.io/browserless/chromium:latest`):

1. **Параметры окружения Browserless**:
   - `TOKEN=your_strong_secret_token` — защитный токен для доступа.
   - `TIMEOUT=86400000` — таймаут сессии браузера в мс (24 часа), чтобы соединение не рвалось через 30 секунд простоя.
   - `CONCURRENT=2` — количество параллельных браузерных сессий (минимум 1–2).
2. **WebSocket URL**:
   - Внутри одной сети Coolify/Docker:
     `ws://browserless:3000/chromium?token=your_strong_secret_token&timeout=86400000`
   - При подключении через внешний домен по TLS:
     `wss://browserless.yourdomain.com/chromium?token=your_strong_secret_token&timeout=86400000`

## Пошаговое развёртывание в Coolify

1. **Создайте сервис Browserless**:
   - В Coolify выберите проект -> **New Service** / **Docker Image** -> `ghcr.io/browserless/chromium:latest`.
   - В настройках Environment Variables задайте:
     - `TOKEN=ваш_токен`
     - `TIMEOUT=86400000`
     - `CONCURRENT=2`
   - Запустите сервис Browserless.

2. **Создайте приложение воркера бота**:
   - В том же проекте и том же **Destination** (одна Docker-сеть с browserless) выберите **New Resource** -> **Application** -> **Private/Public Repository**.
   - Укажите репозиторий с ботом и ветку.
   - **Build Pack**: выберите **Dockerfile**.
   - **Domains / Ports**: оставьте пустыми (бот является фоновым воркером и не слушает входящий HTTP-трафик).
   - **Health Checks**: **ОТКЛЮЧИТЕ** (Disable Healthcheck), так как приложение не слушает HTTP-порт.

3. **Заполните переменные окружения в Coolify**:
   - Скопируйте список переменных из `.env.example`.
   - **КРИТИЧЕСКИ ВАЖНО**: Для переменных `MAIN_PASSWORD` и паролей в `DONOR_ACCOUNTS` (особенно если они содержат символы `$`, `!`, `@`), включите чекбокс **"Is Literal"** в интерфейсе Coolify. Без этого Coolify попытается интерполировать символы `$` как переменные окружения, что сломает пароли!

4. **Запуск и логи**:
   - Нажмите **Deploy**.
   - Перейдите на вкладку **Logs** и убедитесь в успешном старте:
     ```
     [YYYY-MM-DD HH:MM:SS] [INFO] [vfs_bot]: Запуск VFS Global Italy Slot Monitor
     [YYYY-MM-DD HH:MM:SS] [INFO] [vfs_bot.browser]: Подключение к Browserless...
     [YYYY-MM-DD HH:MM:SS] [INFO] [vfs_bot.telegram]: Слушатель входящих сообщений запущен.
     [YYYY-MM-DD HH:MM:SS] [INFO] [vfs_bot.monitor]: Рабочий цикл запущен.
     ```

```bash
pytest tests/ -v
```

### 2. Экспресс-проверка связи с Browserless
Перед боевым запуском проверьте доступность Browserless и сайта VFS:
```bash
python check_connection.py --ws "ws://localhost:3000/chromium?token=TOKEN&timeout=86400000"
```
Скрипт откроет страницу логина VFS, сделает снимок `check_connection.png` и выведет статус ответа.

## Команды Telegram-бота

Пользователи из белого списка `TG_CHAT_IDS` могут отправлять боту следующие команды:

- `/status` — актуальное состояние монитора, аптайм, активный донор, количество проверок и история найденных слотов.
- `/screenshot` — получить свежий снимок экрана текущей страницы браузера.
- `/resume` — досрочно возобновить мониторинг (например, после паузы от нахождения слота).
- `/pause [минуты]` — временно приостановить проверку слотов на указанное количество минут (по умолчанию 60).
- **Любой текст/вопрос** — бот делает скриншот и передает его с вопросом в GPT-4o-mini Vision, возвращая детальный ответ.

## Известные риски и ограничения

1. **Cloudflare Turnstile**:
   VFS Global периодически активирует невидимую капчу Cloudflare Turnstile. В коде реализован поиск и клик по чекбоксу Turnstile. Если Cloudflare блокирует запросы по признаку дата-центрового IP-адреса, рекомендуется использовать резидентские прокси в конфигурации Browserless (`--proxy-server=...`).
2. **Лимиты VFS (Ошибка 429)**:
   При частых запросах VFS накладывает временный бан на аккаунт или IP-адрес на 2–4 часа. Бот автоматически меняет донорский аккаунт и выдерживает паузы между городами (15–25 сек) и кругами (3–5 мин).
3. **Ручное оформление слота**:
   VFS часто меняет верстку шага ввода OTP/паспорта, поэтому автоматическое завершение записи отключено в целях безопасности: бот логинится в основной аккаунт, держит сессию открытой и отправляет уведомление со ссылкой на живой браузер.
